## 3. Color System

All colors are semantic. No flat gray (`#666`–`#999`) on pure white.

| Role | Token | Value | Usage |
|---|---|---|---|
| Background | `color.background` | `#FAFAFA` | Page canvas |
| Surface | `color.surface` | `#FFFFFF` | Cards, modals, elevated panels |
| Text | `color.text` | `#1A1A17` | Primary body text |
| Muted | `color.muted` | `#6B6B75` | Secondary text, captions |
| Border | `color.border` | `#E8E8E6` | Dividers, input borders |
| Accent | `color.accent` | `#0055FF` | Primary CTA, links, focus |
| Danger | `color.danger` | `#DC2626` | Errors, destructive actions |
| Success | `color.success` | `#059669` | Confirmations, valid states |
| Warning | `color.warning` | `#D97706` | Alerts, pending states |

**Accessibility target**: WCAG 2.1 AA for normal text (4.5:1), large text (3:1).

## 8. Motion & Interaction

### 8.1 Allowed Properties

Only `transform`, `opacity`, `filter`, `clip-path` may animate. Animating `width`, `height`, `margin`, `padding`, `top`, `left` is forbidden.

### 8.2 Timing

| Token | Value | Usage |
|---|---|---|
| `motion.duration.fast` | `0.15s` | Micro-interactions |
| `motion.duration.base` | `0.25s` | Standard transitions |
| `motion.duration.slow` | `0.45s` | Page-level reveals |

### 8.3 Easing

- Product easing: `{cubic-bezier values}`
- Exit easing: `cubic-bezier(0.4, 0, 1, 1)`

### 8.4 Reduced Motion

All motion must respect `prefers-reduced-motion: reduce` by disabling transforms and opacity transitions.

### 8.5 States

Every interactive color must define:
- `hover`
- `focus`
- `active`
- `disabled`

Hover states must not rely on opacity alone. Use `transform`, color shift, or underline logic.

## 10. Anti-Slop Gates

Before any code is generated, the following checks must pass:

| # | Gate | Rule |
|---|---|---|
| 1 | Forbidden fonts | No font from the forbidden list appears anywhere |
| 2 | Default fonts | No Inter, Roboto, Helvetica, Arial, etc. |
| 3 | Flat gray | No `#666`–`#999` text on `#FFFFFF` background |
| 4 | Generic shadows | No `shadow-md`/`shadow-lg` on every card |
| 5 | Uniform spacing | Scale is non-linear with ≥3 distinct levels |
| 6 | Generic 3-col | 3-column layouts require asymmetry/disruption rationale |
| 7 | Gradient blobs | No meaningless decorative gradients |
| 8 | Layout animations | No `width`/`height`/`top`/`left` animations |
| 9 | Hover banality | Hover must not be opacity-only |
| 10 | Mass fade-in | No blanket fade-in on scroll without stagger/transform |
| 11 | Scale contrast | Adjacent type sizes differ by ≥1.2× |
| 12 | Semantic palette | Colors have surface/text/border/accent/muted/danger/success/warning roles |
| 13 | Type pairing | ≥2 distinct fontFamily roles |
| 14 | State completeness | Interactive colors define hover/focus/active/disabled |
