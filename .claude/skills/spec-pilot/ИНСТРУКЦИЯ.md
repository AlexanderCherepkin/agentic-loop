# Инструкция по установке spec-pilot

## За 2 минуты

1. Скопируй папку `spec-pilot/` в скиллы Claude Code:
   - **Глобально (для всех проектов):** `~/.claude/skills/spec-pilot/`
   - **Или в конкретный проект:** `<твой-проект>/.claude/skills/spec-pilot/`

2. Открой проект в Claude Code.
   - Если папка `.claude/skills/` создалась впервые — **перезапусти Claude Code**, чтобы skill подхватился.

3. Просто скажи обычными словами, что хочешь собрать:

   > Хочу бота, который принимает заявки и складывает их в таблицу.

   > spec-pilot: собери лендинг под запись на консультацию.

## Что будет дальше

Claude проведёт скоупинг, задаст не больше 3 вопросов (medium) или 8 вопросов (large), напишет спеку и попросит явного «ок». Только после одобрения начнёт сборку.

## Если Claude рванул раньше

Скажи стоп-фразу:

> «стоп, сначала спека»

Claude вернётся к спеке.

## Важно

- Для проекта `Agentic_Loop_Graph` этот skill не обязателен: внутренняя архитектура уже содержит нативных агентов, реализующих тот же порядок (task scoping, spec approval gate, verification planner, skill packager).
- Используй `spec-pilot` в других проектах, где таких агентов нет.
