# TECHNICAL_ASSIGNMENT.md

## Интернет-магазин электроники и гаджетов для рынка Беларуси

**Дата:** 2026-08-23  
**Бриф-источник:** `E-COMMERS.md` + референсные скриншоты `shablons/scrinhost.png`, `scrinhost1.png`, `scrinhost2.png`  
**Цель:** Создать современный, премиальный, продающий интернет-магазин электроники и гаджетов, адаптированный для законодательства и потребителей Республики Беларусь. Будущий сайт должен повторять **структуру, компоновку секций, UX-паттерны и пропорции референсного сайта на 95–99%**, но использовать **уникальный брендинг, собственный логотип, оригинальные тексты, уникальные изображения и адаптированный контент для рынка РБ**. Это не прямой копипаст: сохраняется визуальная архитектура, но всё идентифицирующее референсный бренд заменяется.

---

## 1. Общее описание проекта

### 1.1 Продукт
Интернет-магазин электроники, гаджетов, умных устройств и аксессуаров с фокусом на:
- смарт-часы и фитнес-браслеты;
- беспроводные наушники и аудиотехнику;
- смартфоны и планшеты;
- ноутбуки и компьютерную периферию;
- умный дом и гаджеты для здоровья;
- аксессуары (ремешки, кейсы, зарядные устройства, кабели).

### 1.2 Целевая аудитория
- Резиденты РБ, возраст 18–45 лет;
- покупатели техники Apple/Samsung/Xiaomi/Huawei/Honor и др.;
- пользователи, ценящие премиальный дизайн, удобный UX и надёжную доставку;
- мобильные покупатели (≥60% трафика ожидается с мобильных устройств).

### 1.3 Рынок
Республика Беларусь. Языки интерфейса: русский (основной), белорусский (второй), с возможностью добавления английского. Валюта: белорусский рубль (BYN), отображение цен с копейками. Оплата и доставка — по законодательству РБ.

## 2. Правовые требования (обязательно)

1. Сайт разрабатывается для юридически оформленного продавца (ИП / ООО РБ).
2. В футере и на отдельной странице «О компании» размещаются:
   - полное наименование организации / ФИО ИП;
   - УНП;
   - юридический и фактический адрес;
   - телефон, email, режим работы;
   - сведения о включении в Торговый реестр РБ;
   - банковские реквизиты (опционально, для юрлиц).
3. Обязательные правовые страницы:
   - Политика конфиденциальности (согласно законодательству РБ о персональных данных);
   - Пользовательское соглашение;
   - Условия продажи и возврата (14 дней на непродовольственные товары надлежащего качества для покупателей РБ);
   - Гарантийные условия по категориям товаров.
4. Cookie consent: баннер согласия на использование cookies и аналитики.
5. HTTPS, SSL-сертификат.

## 3. Технологический стек

### 3.1 Frontend
- **Next.js 15** (App Router, React Server Components, Server Actions);
- **TypeScript** — strict mode;
- **Tailwind CSS 4** для стилизации;
- **Radix UI / shadcn/ui** для доступных компонентов (диалоги, селекты, аккордеоны, слайдеры);
- **Framer Motion** — анимации, hover, скролл-триггеры, sticky-сайдбар;
- **Lucide React** — иконки.

### 3.2 Backend / Data
- **Next.js Server Actions** — корзина, избранное, заказы, поиск;
- **Prisma ORM + PostgreSQL** — каталог, пользователи, заказы;
- **NextAuth.js / Clerk** — авторизация (этап 2);
- **Mock-контент** на старте, возможность миграции на CMS/1С позже.

### 3.3 Инфраструктура
- **Docker** (опционально) — `Dockerfile` + `docker-compose.yml` уже есть;
- **runtime-движки агент-бота** — i18n, analytics, accessibility, PWA, design-token docs, code-review, security-scan, quality-evaluator;
- **Vercel / собственный сервер** — развёртывание по согласованию.

## 4. Визуальная концепция

### 4.1 Референс
Скриншоты `shablons/scrinhost.png`, `scrinhost1.png`, `scrinhost2.png` — премиальный магазин электроники (визуальный стиль tech-minimal).  
**Принцип использования:** структура и UX берутся из референса, но визуальный стиль адаптируется под собственный бренд. Название, логотип, тексты, изображения продуктов, бейджи и подписи — уникальные.

### 4.2 Стилистика
- **Направление:** premium tech minimalism;
- **Фон:** чистый белый `#FFFFFF` с мягкими серыми секциями `#F6F6F6` / `#F8F9FA`;
- **Текст:** глубокий чёрный `#0A0A0A` / `#111111`;
- **Акцент:** яркий синий `#2563EB` или бирюзовый `#0EA5E9` для CTA и бейджей;
- **Типографика:** современный гротеск для UI + элегантный serif/display-шрифт для заголовков hero;
- **Изображения:** крупные, чистые, на светлых фонах, с тенями и объёмом;
- **Отступы:** generous whitespace, 80–120 px между секциями на десктопе;
- **Скругления:** карточки `rounded-2xl`, кнопки `rounded-full` или `rounded-xl`;
- **Тени:** мягкие тени для карточек и изображений.

### 4.3 Motion system
- Easing: `cubic-bezier(0.16, 1, 0.3, 1)`;
- Длительность: 0.3–0.5 s;
- Hover: lift + scale 1.02 на карточках товаров;
- Scroll-triggered: fade-in + translateY(24px → 0);
- Hero: продукт плавно появляется/парит;
- Sticky боковое меню категорий (как в референсе) — при скролле появляется справа и сдвигается/фиксируется для навигации по разделам.

### 5.1 Шапка (Header) — как в референсе

- Справа: телефон поддержки, иконка аккаунта, иконка избранного, иконка корзины с суммой.

### 5.2 Hero-баннер
- Полноширинный слайдер / статический баннер;

### 5.3 Collections (Подборки)

### 5.6 Value Proposition

### 5.7 Product showcase (развёрнутый) — как в референсе

- Карточка рекомендуемого товара поверх изображения.
**Важно:** повторить компоновку «полноширинное фото + overlay-карточка товара + бейдж-акция».

### 5.8 Benefits strip
- Иконки + текст:

### 5.9 Reviews / «What clients say»

### 5.10 Blog / News

### 5.11 FAQ («Our common questions»)

### 5.12 Instagram / Lifestyle Gallery
- Сетка 4–6 изображений из Instagram / lifestyle;

### 5.13 Subscribe
- Фон тёмный / градиент;
- Заголовок «Subscribe to our emails»;

### 5.14 Футер
- 4 колонки:

## 8. Корзина и оформление заказа

### 8.1 Корзина
- Боковое drawer / отдельная страница;
- Список товаров с миниатюрами, ценой, количеством, удалением;
- Промокод;
- Итог: сумма, скидка, доставка, к оплате.

### 8.2 Оформление заказа
- Шаги:
  1. Контакты (имя, телефон, email);
  2. Доставка (Белпочта / курьер / самовывоз из ПВЗ) + адрес;
  3. Оплата (ЕРИП / карта Белкарт / Apple Pay / Samsung Pay / наличные при получении);
  4. Подтверждение.
- Авторизация не обязательна для оформления (гостевая покупка);
- Личный кабинет — этап 2.

### 8.3 Интеграции (MVP — заглушки + точки расширения)
- **ЕРИП** — формирование счёта (заглушка + документация по подключению);
- **Эквайринг** — заглушка для карт;
- **Белпочта / курьер** — ручной расчёт стоимости, форма адреса;
- **1С / склад** — этап 2, сейчас механизм обновления остатков через админку.

## 16. Ассеты и контент

- **Изображения:** использовать мок-изображения техники на светлых фонах в стиле референса. Заменить «Woodstock» и любую другую брендовую графику референса на уникальный бренд.

- **Структура:** повторить компоновку секций референса на 95–99%: шапка, hero, collections, featured products, split banner, value prop, promo showcase, benefits, reviews, news, FAQ, gallery, subscribe, footer.

## 17. Анти-слив / Anti-slop

- Не использовать шаблонные Unsplash-заглушки без обработки;
- **Не копировать контент референсного бренда (названия, логотип, тексты, подписи, бейджи);**
- **Сохранять структуру, компоновку и UX референса на 95–99%**, адаптируя визуал и копирайтинг под собственный бренд;
- Использовать единую типографику и палитру;
- Избегать перегруженных hero-изображений и центрированных «3 карточек преимуществ».
