# Шпаргалка «6 фраз для Claude Code»

## 1. «Хочу собрать…» / «Хочу бота на…»

Сказать обычными словами, что нужно построить.

**Правильный ответ Claude:** провести интервью (medium ≤3 вопроса, large ≤8) и написать спеку.

**Как не надо:** сразу запустить саб-агентов или начать кодить.

---

## 2. «Ок» / «Да» / «Согласен» / «Продолжай»

**Явное одобрение спеки** перед любой параллельной работой.

Approval markers: `да`, `ok`, `yes`, `продолжай`, `собирай`, `согласен`, `давай`, `+`.

**Не является одобрением:** молчание, «сделай как лучше», «на твоё усмотрение», «выглядит ок», «вроде норм", «давай попробуем», out-of-context «ок».

---

## 3. «Стоп, сначала спека»

Если Claude рванул в параллель до одобрения — осадить.

Эквиваленты: «стоп, спека», «сначала спека», «не запускай агентов», «stop, spec first".

---

## 4. «Собери» / «Запусти по спеке»

Запуск параллельных/последовательных саб-агентов **только после** одобренной спеки.

---

## 5. «Проверь»

Требовать верификацию перед сдачей: тесты, линтеры, скрипты, скриншоты, ручная проверка.

Hand off only after verified output.

---

## 6. «Упакуй в скилл»

После задачи — извлечь gotchas и сделать reusable skill. Требует явного одобрения на запись skill-файла.

---

## Правильный порядок

```
1. Сказать, что собирать
2. Интервью + спека
3. Явное «ок»
4. Параллель/сборка по спеке
5. Проверка
6. Упаковка gotcha в skill (опционально)
```

## Главная ошибка

`launch sub agents` **ДО** спеки = слив лимита на гадание и переделки.
